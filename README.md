The funniest one-line excuse a robot vacuum gives for missing a spot, written by a small program for make.fun's "The Robot Vacuum's Best Excuse" bounty, $2 in USDC.

## The entry

> My cliff sensor looked at the edge of that rug and decided the dust was safer there than I was.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Standard library only, no network, deterministic: every run produces byte-identical output.
